# UUID Generator

This repository contains a simple UUID generator script, [`uuid_generator.sh`](https://github.com/Akash6222/uuid_generator/blob/main/uuid_generator.sh), which uses the `uuidgen` command to create random UUIDs based on user input.

## How it works

1. The script prompts the user to enter the number of UUIDs they want to generate.
2. It then generates the specified number of UUIDs and stores them in a file named `uuids.txt`.
3. The generated UUIDs are displayed after creation.

### Usage

Run the script and input the number of UUIDs you'd like to generate.

```bash
bash uuid_generator.sh
```
